# 离线随机密码生成器

一个完全离线的浏览器端随机密码生成工具，支持多种自定义规则，本地生成，隐私安全。

## 功能特性

### 核心功能
- 自定义密码长度 (1-20位)
- 支持同时生成多个密码
- 一键复制单个密码或全部复制
- 完全离线运行，数据不离开浏览器

### 密码规则选项
- **字符类型选择**：大写字母、小写字母、数字、特殊符号
- **强制首字母大写**
- **排除易混淆字符** (I/l/1/O/0 等)
- **自定义排除字符** - 可指定不想要的任意字符
- **自定义特殊符号** - 可指定只使用哪些特殊符号
- **排除弱密码关键词** - 默认屏蔽常见弱密码词如 `admin`, `pass`, `root` 等

### 智能规则
- 每种选中字符类型**至少占 25%**，保证密码复杂度
- **特殊符号不允许连续出现**，提高安全性
- 首字母大写时自动排除易混淆字符

### 便捷体验
- **自动保存配置** - 使用 localStorage 保存所有设置，下次打开自动恢复
- **中英文切换** - 根据浏览器语言自动显示中文或英文，也可手动切换并记住选择
- **页签图标** - 内置锁形 SVG favicon，浏览器标签页更易识别
- 分栏布局，左侧密码列表支持独立滚动
- 响应式设计，适配不同屏幕尺寸

## 使用方式

直接用浏览器打开 `password-generator.html` 即可使用，无需部署，无需服务器，完全离线运行。
